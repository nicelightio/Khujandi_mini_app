1. Выбери маленькую фичу. Не “сделай дизайн всего проекта”, а, например: Экран авторизации

Опрос
```
Используй skill grill-me. Помоги мне прояснить дизайн фичи: [название фичи]. Сначала изучи текущий проект, если можешь найти ответы в коде — не спрашивай меня. Задавай вопросы по одному блоку: пользователь, сценарий, экраны, визуальный стиль, ограничения.
```

по окончанию опроса
```
Используй skill design-brief. На основе нашего обсуждения и текущего кода проекта создай DESIGN_BRIEF.md для фичи [название фичи]. Учитывай стек проекта: HTMX + Jinja + Alpine.js + CSS variables. Не предлагай React.
```

```
Используй skill information-architecture для фичи [название фичи]. Опиши структуру экранов, user flow, навигацию, состояния экранов и список UI-блоков. Не пиши код.```

```
Используй skill design-tokens. Создай дизайн-токены для этой фичи, но не ломай существующую тему проекта. Если в проекте уже есть CSS variables или theme-файлы — расширяй их, а не заменяй. Формат предпочтительно CSS variables. Без React, без shadcn.
Сначала предложи изменения токенов как diff/proposal, не применяй автоматически.
```


```
Используй skill brief-to-tasks. Разбей дизайн фичи на маленькие vertical slices. Каждый slice должен давать видимый результат, который можно проверить в браузере. Не делай задачи по слоям типа "сначала CSS", "потом HTML"; делай по пользовательской ценности.
Хорошая задача должна быть типа:

Slice 1: пустой dashboard с layout, header, sidebar и базовой навигацией.
Slice 2: карточки ключевых метрик.
Slice 3: список последних событий.
Slice 4: empty/error/loading states.
```


```
Используй skill frontend-design. Реализуй только Slice 1 из TASKS.md. Стек: HTMX + Jinja + Alpine.js + CSS variables. Не используй React. Переиспользуй существующие шаблоны, компоненты и стили проекта. Не создавай новый UI-kit, если уже есть подходящие элементы.
```


```
Используй skill design-review. Проверь реализованный Slice 1 визуально: desktop, tablet, mobile, light/dark если есть. Найди проблемы с иерархией, отступами, адаптивом, контрастом, состояниями и переполнением.
```
