Разрабатываем Агента "SweetLeads". 
Mission of SL Agent: Telegram Group and Channel Monitoring System for Generating Targeted Leads.
Система мониторинга сообществ и каналов Telegram для  генерации целевых лидов.
Представляет из себя симбиоз телеграм Ботов и ИИ Агента.

**Краткое описание функционала Лидсканера**
 Хозяин указывает параметры для таргета:
 - гео,
 - ключевые слова для поиска,
 - тематики telegram-сообществ, 
 Бот передает параметры Таргета Агенту, система анализирует на сколько качественно подобраны параметры таргета и предлагает улучшения по параметрам, особенное внимание уделяет подбору ключевых слов.
Происходит обсужение параметров таргета и финальное утвержение.
Бот переходит к процессу ресерчинга. Это кропотливый и длительный процесс сбора данных в таблицы.
Бот выдает саммари по результату ресерчинга.
Пользователь указывает характеристики для репорта по ресерчингу.
Бот выдает саммари репорта по указанным характеристика и формирует таблицу пользователей репорта, сохраняет ее в бд с пометкой характеристик репорта.
Бот перенаправляет таблицу репорта другому независимому агенту либо создает такую таблицу в гугл документах. 

**Подробное описание Процесса ресерчинга**
1. Бот начинает мониторинг источников  (сообществ и каналов в телеграмм), подходящих под тематику, составляет два списка(списки сырцов) - список каналов и список групп. 
2. Бот анализирует контент в каждом источнике из двух списков сырцов, присваивая источнику рейтинг от 1 до 5 (1 - источник слабо подходит, 5 - источник очень подходит под тематику). 
Бот упорядочивает в "списках сырцов" все источники от рейтинга  5 до 1, создава дфе финальных таблицы источников: таблица груп по рейтингу (ТГР) и таблица каналов по рейтингу (ТКР). 
3. Бот начинает анализ ТГР.
3.1 Создание таблицы ТЮГ.
Бот берет первый источик из ТГР и составляет таблицу всех юзеров, находящихся внутри источника (ТЮГ). 
Если пользователей из источника нельзя получить, ичтоник добавляется в таблицу скрытых источников (ТСИ), бот переходит к следующему источнику из ТГР.
Если тип пользователя -  бот, он не вносится в таблицу ТЮГ. 
3.2 Поля таблицы ТЮГ:
   - user ID
   - тип источника (канал, открытая группа, закрытая группа)
   - количество сообщений в источнике от этого user
   - user рейтинг( по умолчанию - 0)
   - сколько есть других источников из ТГР и ТКР, в которых присутствует user ( по умолчанию 0).
Поля таблицы ТЮГ не заполняются сразу. 
3.2.1 Сначала бот получает список всех пользователей сырца и создает ТЮГ, заполняя только поле User ID. 
После того как таблица ТЮГ для данного сырца создана, бот начинает анализ по каждому пользователю из таблицы, заполняя остальные поля, кроме последнего.
3.2.2 Указывается тип источника (канал \ группа ) 
3.2.3 Бот ищет количество сообщений от user ID в сырце и заполняет поле таблицы.
3.2.4 Бот определяет user рейтинг на основании поиска по ключевым словам среди всех сообщений пользователя в сырце.
3.2.5 присутствие пользователя в других источниках ТГР и ТКР вносится после того как будут созданы все таблицы ТЮГ и ТЮК из списка таблиц ТГР и ТКР.
4. Бот проделывает в    се шаги анализа из пункта 3 для ТКР, составляя таблицы юзеров каналов (ТЮК)
